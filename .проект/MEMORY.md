# Память проекта

Обновлено: 2026-11-14

## Цель
Сайт-портфолио Katja North на GitHub Pages: показать ИИ-видео работодателям и клиентам, привести к работе нейрокреатором или заказам.

## Решения
- Правила работы ИИ — `AGENTS.md`, подключены через `CLAUDE.md`.
- Языки сайта: английский (основной) + датский. Русский пока не делаем.
- Обязательное требование: адаптивный дизайн (компьютер, планшет, телефон, обе ориентации) — подробно в README.
- После каждого этапа — объяснять Кате, как проверить вид на разных экранах (закреплено в AGENTS.md).
- Структура: одна страница, меню ведёт к разделам — главный экран, работы, услуги, обо мне (+ инструменты), контакты. Подробно в README.
- Видео не храним в репозитории (тяжело, медленно) — только ссылки/встраивание.
- Ролики из Instagram/Telegram перезаливаем на YouTube (Shorts); на сайте — только YouTube. Раскладка: 4 горизонтальных (2×2) + 4 вертикальных (ряд) — см. `материалы/работы.md`.
- Оформление: чёрный + серебро + акцент #5CE1FF; шрифты Cormorant + Manrope, локально.
- Контакты: кнопки LinkedIn, YouTube, Instagram (без Telegram) + форма через Formspree: имя, e-mail, тема, сообщение (без телефона).
- Хостинг — GitHub Pages, репозиторий публичный (личных данных не хранить).
