# Оглавление правил проекта

Корневой `AGENTS.md` заполнен до предела (12 000 байт), поэтому все тематические правила лежат в этой папке.
**Новое правило:** создай здесь файл `имя-темы.md` (когда применять → шаги → проверка результата) и добавь строку в таблицу ниже. В `AGENTS.md` ничего не добавляй.

## Какое правило читать
| Если задача про… | Читай |
|---|---|
| ролик на первом экране сайта (поставить, заменить) | `ролик-главного-экрана.md` |
| ролики в разделе Work: добавить, заменить, убрать, переставить, поменять название или описание | `ролики-портфолио.md` |
| политику конфиденциальности, CVR, почту, срок хранения, сервисы, ссылки на соцсети, свой домен | `политика-и-контакты.md` |
| новый сайт по этому образцу: другой владелец, другие ролики, тексты, языки | `новый-сайт-по-образцу.md` |

## Где что лежит в проекте
| Что ищешь | Где |
|---|---|
| Общий порядок работы и договорённости с Катей | `AGENTS.md` (корень) |
| Карта проекта: назначение, файлы, оформление, как проверять | `README.md` (корень) |
| Что решено, что сделано, что открыто, следующий шаг | `.проект/MEMORY.md` |
| Английский текст сайта | `index.html`, `privacy.html` |
| Датский текст сайта | `assets/i18n/da.json` |
| Настройки языков и адреса сайта | блок НАСТРОЙКИ в `.проект/инструменты/sborka.py`; строки формы — список `UI` в `assets/js/main.js` |
| Датские страницы (не править руками) | `da/` — создаёт `python3 .проект/инструменты/sborka.py` |
| Оформление, поведение | `assets/css/style.css`, `assets/js/main.js` |
| Обложки роликов, логотип, фото | `assets/img/` |
| Список работ, ссылки на YouTube, согласия клиентов | `материалы/работы.md` |
| Исходные тексты, логотипы, фото от Кати | `материалы/` |
| Команды-помощники | `.проект/инструменты/` |

## Команды-помощники
| Команда | Что делает |
|---|---|
| `python3 .проект/инструменты/sborka.py` | пересобирает датские страницы, карту сайта; запускать после любой правки текста |
| `python3 .проект/инструменты/rolik-portfolio.py …` | готовит ролик YouTube для раздела Work |
| `python3 .проект/инструменты/rolik-glavnogo-ekrana.py …` | ставит ролик первого экрана |
| `python3 .проект/инструменты/predprosmotr.py <файл.html>` | собирает главную страницу в один файл для закрытого предпросмотра |

## Что нужно для проверки живого сайта
Рабочая среда «katja-north-site»: в ней открыт доступ к YouTube, обложкам, Formspree и адресу сайта. Живой сайт: см. раздел «Публикация» в `README.md`.
