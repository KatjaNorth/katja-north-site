# Ролики портфолио: добавить, заменить, убрать, переставить

## Когда применять
Катя просит добавить новый ролик в раздел Work, заменить или убрать существующий, поменять порядок, название или описание.
Ролик на самом первом экране — другая тема: `.проект/правила/ролик-главного-экрана.md`.

## Как устроено
- Ролики лежат на YouTube. На сайте — обложка (`assets/img/covers/<номер ролика>.webp`); плеер загружается только по нажатию.
- Номер ролика — 11 знаков из ссылки: `youtu.be/XXXXXXXXXXX` или `youtube.com/shorts/XXXXXXXXXXX`.
- Один ролик в `index.html` — это блок `<figure class="video wide">` (горизонтальный 16:9) или `<figure class="video tall">` (вертикальный 9:16).
- Раздел Work состоит из двух блоков: «Personal projects» (первый) и «Client work». Внутри — ряды.
- Английский текст — в `index.html`, датский — в `assets/i18n/da.json`. Страницу `da/index.html` руками не править.

## Правило рядов (чтобы сетка на компьютере не ломалась)
Ряд бывает только двух видов:
- `<div class="row-mix">` — **один горизонтальный + два вертикальных**, именно в таком порядке;
- `<div class="row-two">` — **два горизонтальных** (один горизонтальный тоже допустим: он встанет слева в половину ширины).

Отсюда: вертикальные ролики добавляются **парами** вместе с одним горизонтальным; горизонтальные — по два.
Если количество не сходится — не выдумывай новый вид ряда, а скажи Кате, какого ролика не хватает для ровного ряда, и предложи варианты.

## Что спросить у Кати перед работой
1. Ссылку на YouTube. Доступ ролика — «Открытый» или «По ссылке».
2. Вертикальный он или горизонтальный (если не ясно из ссылки `shorts`).
3. В какой блок: свои проекты или заказы. **Для заказа — подтверждение, что клиент разрешил показывать ролик.**
4. Название и одну строку описания (можно по-русски — переведи на английский и датский, датский дай Кате на проверку).
5. Куда поставить и что делать с парой, если ряд не сходится.

## Добавить ролик
1. `git pull origin main`.
2. Запусти (wide — горизонтальный, tall — вертикальный):

   ```bash
   python3 .проект/инструменты/rolik-portfolio.py "<ссылка>" tall "Название" "Описание по-английски" "Описание по-датски"
   ```

   Команда скачает обложку, запишет датское описание в `da.json` и напечатает готовый блок `<figure>`.
   Если она пишет `ОШИБКА` про обложку — проверь ссылку и доступ к адресу `i.ytimg.com` (рабочая среда «katja-north-site»).
3. Вставь напечатанный блок в `index.html` в нужный ряд по правилу рядов. Новый ряд — это новый `<div class="row-mix">…</div>` или `<div class="row-two">…</div>` рядом с существующими, внутри того же блока.
4. Если ролик — пример для услуги: добавь ему `id`, например `<figure id="ex-3d" class="video tall">`, и проверь, что ссылка «See example» нужной карточки в разделе Services ведёт на `#ex-3d`. Уже занятые `id`: `ex-commercials`, `ex-music`, `ex-historical`, `ex-animation`, `ex-social`, `ex-3d`. Один `id` — только у одного ролика.
5. Запусти сборку: `python3 .проект/инструменты/sborka.py`. Последняя строка должна начинаться с `Готово:`. Если она пишет `ЕСТЬ ЗАМЕЧАНИЯ` — исправь названное и запусти снова.

## Заменить ролик на другой
1. Запусти ту же команду для нового ролика (шаг 2 выше) — получишь новый блок.
2. В `index.html` найди старый блок по номеру ролика (`data-yt="СТАРЫЙ_НОМЕР"`) и замени весь `<figure …>…</figure>` новым блоком. Если у старого был `id="ex-…"` — перенеси его на новый.
3. Формат (wide/tall) должен остаться тем же, иначе сломается ряд.
4. Удали из `da.json` ключ описания старого ролика (`cap.…`), иначе сборка сообщит о лишнем ключе. Файл старой обложки можно удалить только с разрешения Кати (правило из `AGENTS.md`).
5. Сборка: `python3 .проект/инструменты/sborka.py`.

## Поменять только название или описание
- Название: в блоке ролика три места — `data-title="…"`, `aria-label="Play video: …"` и `<strong>…</strong>`.
- Английское описание: текст внутри `<span data-i18n="cap.…">`. Датское: тот же ключ в `assets/i18n/da.json`.
- Сборка: `python3 .проект/инструменты/sborka.py`.

## Убрать или переставить ролик
- Переставить: перенеси блок `<figure>` целиком, соблюдая правило рядов и порядок «горизонтальный, вертикальный, вертикальный».
- Убрать: удали блок `<figure>` и его ключ из `da.json`. Если на ролик вела ссылка «See example» — согласуй с Катей другой пример, пустая ссылка недопустима.
- Сборка: `python3 .проект/инструменты/sborka.py`.

## Проверка результата
1. `python3 -m http.server 8765`, открой `http://localhost:8765/` и `http://localhost:8765/da/`.
2. Размеры экрана (Chrome: F12 → Ctrl+Shift+M): компьютер 1366×768, планшет 820×1180 и 1180×820, телефон 390×844 и 844×390.
3. Что должно быть:
   - в каждом ряду `row-mix` все три рамки одной высоты (на телефоне стоя: горизонтальный сверху, два вертикальных под ним);
   - обложка нового ролика видна, под ней название и описание — на обоих языках;
   - по нажатию ролик запускается (если сеть не пускает к YouTube — проверь хотя бы, что вместо обложки появился плеер, и попроси Катю проверить на живом сайте);
   - ссылки «See example» всех шести услуг ведут к роликам, рамка подсвечивается;
   - страница не прокручивается вбок, в консоли нет ошибок.

## Сохранение
```bash
git add -A
git commit -m "Ролик портфолио: <что сделано>"
git push origin main
```
Через 1–3 минуты проверь живой сайт (обе языковые страницы). Обнови `материалы/работы.md` (ссылка, формат, согласие клиента) и `.проект/MEMORY.md`. Объясни Кате, как посмотреть результат на компьютере, планшете и телефоне.
