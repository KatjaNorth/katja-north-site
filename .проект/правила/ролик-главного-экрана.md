# Ролик главного экрана

## Когда применять
Катя прислала два ролика для главного экрана (первый экран сайта) или просит их заменить.

## Что должно получиться
На главном экране вместо обложки с кнопкой «play» стоит ролик, который сам запускается без звука и крутится по кругу.
Под ним, как и раньше, подпись «AI video creator», слоган и две кнопки — их не трогать.
- Экран в горизонтальном положении (компьютер, планшет и телефон на боку) — ролик 16:9.
- Экран в вертикальном положении (телефон, планшет стоя) — ролик 9:16.
- Третий файл для планшета не нужен: рамка сама принимает пропорции ролика, ничего не обрезается.
- Если у посетителя включена экономия трафика или «меньше движения», показывается неподвижный кадр-обложка.

## Что нужно от Кати
Два файла MP4, 10–15 секунд, без звука (звук всё равно будет удалён):
- горизонтальный 1920×1080 (16:9);
- вертикальный 1080×1920 (9:16).

Как она их передаёт: прикрепляет в чат или загружает на GitHub в папку `материалы/` («Add file → Upload files», до 25 МБ на файл).
Если файлы пришли в чат — сохрани их в `материалы/` под именами `ролик-главный-16x9.mp4` и `ролик-главный-9x16.mp4`.

## Шаги
1. Перейди в корень проекта и возьми свежую версию: `git pull origin main`.
2. Проверь, что есть программа сжатия: `ffmpeg -version`. Если её нет — спроси у Кати разрешение на установку (правило из `AGENTS.md`), затем `apt-get install -y ffmpeg`.
3. Запусти одну команду — **сначала горизонтальный файл, потом вертикальный**:

   ```bash
   python3 .проект/инструменты/rolik-glavnogo-ekrana.py материалы/ролик-главный-16x9.mp4 материалы/ролик-главный-9x16.mp4
   ```

   Команда сама: сжимает ролики, убирает звук, делает обложки, кладёт файлы в `assets/video/`, заменяет блок между `<!-- HERO-VIDEO:START … -->` и `<!-- HERO-VIDEO:END -->` в `index.html` и пересобирает датскую страницу `da/index.html`.
4. Прочитай, что напечатала команда:
   - `ОШИБКА: …` — ничего не изменено, исправь причину (чаще всего перепутан порядок файлов) и запусти снова;
   - `ВНИМАНИЕ: … весит … МБ` — ролик слишком тяжёлый, попроси Катю сократить его;
   - последняя строка должна быть `Готово: da/index.html …`.
5. Руками ничего в `index.html`, `da/index.html`, стилях и скриптах менять не нужно — всё уже подготовлено.

## Проверка результата
1. Запусти сайт у себя: `python3 -m http.server 8765` и открой `http://localhost:8765/` и `http://localhost:8765/da/`.
2. Проверь на трёх размерах экрана (в Chrome: F12 → Ctrl+Shift+M):
   - компьютер 1366×768 — ролик широкий, играет сам, под ним подпись и две кнопки, всё помещается в первый экран;
   - планшет 820×1180 (стоя) — ролик вертикальный; 1180×820 (на боку) — широкий;
   - телефон 390×844 — ролик вертикальный; 844×390 (на боку) — ролик слева, текст справа.
3. Страница не должна прокручиваться вбок, в консоли браузера не должно быть ошибок.
4. Файлы `assets/video/hero-wide.mp4` и `hero-tall.mp4` — не больше 4,5 МБ каждый.

## Сохранение
```bash
git add -A
git commit -m "Ролик главного экрана"
git push origin main
```
Через 1–3 минуты проверь живой сайт. Потом:
- запиши сделанное в `.проект/MEMORY.md`;
- объясни Кате, как посмотреть результат на компьютере, планшете и телефоне (в обеих ориентациях).

## Как вернуть прежний вид
`git revert <номер сохранения>` и `git push origin main` — вернётся обложка презентации с кнопкой «play».

## Что уточнить у Кати после установки
Прежний ролик-презентация (YouTube `skiCRepiLbw`) с главного экрана исчезает. Спроси, нужен ли он в другом месте сайта, например первым в «Personal projects».
